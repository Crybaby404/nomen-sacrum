# Analysis plan — DRAFT, NOT YET PREREGISTERED

Created in repository: 2026-11-23. No finalized hypotheses or published statistical tests are claimed. This is a **planning document**, not an approved preregistration, because the first descriptive Kinbank orthographic counts already exist.

## Research questions
1. Is the distribution of predeclared phonetic motifs different between independently sampled sacred names and non-sacred controls after controlling for language family, name length, and transcription source?
2. Are the sound-to-semantic associations (e.g., kinship term → maternal divine title) more frequent among deity names than corresponding ordinary nondivine names?
3. Which examples have established intra-language derivation, historical cognacy, borrowing, or unresolved resemblance?

## Proposed predeclared target classes (NOT FINAL)
- Whole-name and morphologically supported components only.
- Orthographic retrieval sets AN/ANA/ANU, AM/AMA/AMMA/MAMA, YA/YAH/IAO, EL/IL/AL, RA/RE, NU/NUN, BA/PA/TA, DYEU, KA, YAM/YIM, ADAM.
- Historical IPA comparisons will require a period/variety and a documented phonological realization.
- Candidate semantic categories: kin-derived title; divine or ancestral figure; primordial sky; primordial waters; ordinary non-sacred personal or kin term. Specific definitions and exclusions must be fixed *before* confirmatory tests.

## Design requirements before registration
1. Freeze which sacred name records are eligible and publish stratified sampling frame.
2. Publish equal-opportunity nonmatch controls, including matched common nouns and ordinary personal names.
3. Separate language families and historically transmitted name groups. No double-counting direct cognates or equivalents of one deity.
4. State the phonetic distance function and exact IPA transcription eligibility.
5. Account for missing/non-Latin characters instead of treating them as nonhits.
6. Register null test, multiple-comparison correction, effect size and uncertainty intervals.
7. Publish scripts and dataset hashes and record preregistration timestamp in a platform with immutable versioning.

## Exploratory work already performed
The Kinbank orthographic baseline v2 was computed and supplied before this planning document. It is descriptive and **not a confirmatory test** of sacred-name patterns. No attempt to retrospectively label it preregistered is appropriate.

## Decision gate
Freeze and publicly register a final protocol in a timestamped external archive **before** confirmatory testing. Until then this file remains a living draft.
