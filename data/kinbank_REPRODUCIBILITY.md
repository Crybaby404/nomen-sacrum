# Kinbank reproducibility gap

The [Kinbank method](kinbank_method.md), [reported counts](kinbank_counts.csv) and [VNV controls](kinbank_vnv_control.csv) are archived.

**The original calculation script is NOT in this repository.** The computation was described as carried out with an AI assistant and reviewed through a second AI-assisted audit. The corrected v2 totals and the tokenizer correction were supplied in conversation. They have not been independently reproduced from source CSV in this repo.

Reported source: `kinbank/kinbank`, Git commit `925cc0e702ae5481cfe0088aaa0e69c3991000f3`, `cldf/forms.csv`.

A real replication package requires the original script (or a fresh implementation explicitly labeled as such), dependency/environment lock, checksums, source input and generated outputs compared byte-wise or row-wise. Do not claim reproducibility until that check passes.
